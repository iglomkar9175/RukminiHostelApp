# Rukmini Hostel App

Android PG/Hostel management MVP.

## Included
- Dashboard
- Tenant add/list with local persistence
- Room overview
- Payment entry
- More menu for Bills, Reminders, Expenses, Reports, Documents, Notifications, Settings
- GitHub Actions workflow that builds a debug APK

## Build on GitHub
1. Upload this project to a GitHub repository.
2. Open **Actions**.
3. Run **Build Rukmini Hostel APK** (or push a commit).
4. Download the `rukmini-hostel-debug-apk` artifact.

Package: `com.rukmini.hostel`
